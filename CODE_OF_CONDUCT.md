# Code of Conduct

RouterDeck follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be respectful, assume good intent, and help newcomers. Harassment,
discrimination and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainer via
[GitHub](https://github.com/PramithaMJ) or <https://pramitha.lk>. Reports are handled
confidentially.
